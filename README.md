# RingoStrike Research

This repository contains the research, planning, and writing process for a paper about **RingoStrike**, an emotionally supportive habit-building app built around adaptive micro-missions, daily behavior signals, reminders, rewards, and a companion character named Ringo.

## Working Paper Direction

**From Habit Theory to Adaptive Micro-Missions: Designing RingoStrike as an Emotionally Supportive Habit Companion**

## Current Position

This project does **not** claim that RingoStrike has proven long-term habit change.

The current goal is to develop an evidence-informed design framework and early case study that explores how habit formation research, behavior change techniques, adaptive interventions, and emotionally supportive companion design can inform the design of a daily self-improvement app.

## Main Research Question

How can an emotionally supportive digital companion adapt daily micro-missions, feedback, reminders, and rewards based on user behavior to support sustainable habit-building experiences?

## Current Scope

This repository will include:

* Research direction and article planning
* Literature notes
* Feature-to-theory mapping
* Behavior-aware micro-mission framework
* RingoStrike case study notes
* User study planning
* Draft versions of the paper
* AI usage documentation
* Publication planning

## Current Status

Research planning and framework development in progress.

## Important Limitation

RingoStrike is currently an early-stage product and design case study. Any claims about long-term behavior change, psychological effectiveness, or measurable health outcomes require future user studies and stronger evidence.
